# G1.2 FLOC Alignment

Status: `draft`

## Decision Need

Define whether FLOC leaf can move from actionable zero to a usable STINT 2 candidate path through IH06/FLOC alignment.

## Constraints

- FLOC remains a separate namespace from SAP S/B/C/5/A catalogs.
- IH06/KKS-style support may guide alignment but does not automatically resolve hierarchy.
- Zero denominator remains valid unless row-level alignment evidence is produced.
