# Concept ID Registry

Stable concept identifiers prevent downstream stages from referencing mutable text labels.

## Format

```text
RL-{OBJECT}-{NNNN}
```

Examples:

- `RL-CANONICAL-0001`
- `RL-SOURCE-0001`
- `RL-LEXICAL-0001`
- `RL-NORMALISATION-0001`
- `RL-SAP-0001`
